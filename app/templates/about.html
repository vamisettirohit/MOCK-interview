About Mock Interview AI

Mock Interview AI is a college capstone project designed to bridge the gap between academic preparation and industry technical interviews.

Technology Architecture

Backend Engine Python 3.12, Flask, Modular Blueprints, Application Factory pattern
Database MongoDB Atlas cloud cluster via PyMongo with indexed user & interview documents
AI Inference Groq Cloud API leveraging high-speed Llama 3 models with JSON schema enforcement
Security Werkzeug cryptographic password hashing, HTTP-only signed session cookies, input sanitation

Evaluation Methodology

Each student submission is passed through Groq's high-speed inference engine using a multi-criteria grading rubric:

  • Technical Accuracy (40%): Verifies correctness of algorithms, design patterns, protocols, and conceptual principles.
  • Depth & Completeness (30%): Assesses whether edge cases, performance trade-offs, and scalability limitations are addressed.
  • Clarity & Structure (30%): Analyzes communication flow, conciseness, and professional articulation.
